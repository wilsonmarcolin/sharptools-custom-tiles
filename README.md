## 📦 How to Use

### Import a Tile

1. Go to: https://sharptools.io
2. Navigate to: User Page → Custom Tiles
3. Click: **Import**
4. Paste the JSON file URL: https://raw.githubusercontent.com/YOUR-USERNAME/YOUR-REPO/main/tiles/TILE-NAME/TILE-NAME.json
5. Configure as needed following the tile-specific documentation

### Direct Import Links
Each tile has a direct import link in its respective folder for convenience.
